Core blocks functionality for WordPress block themes.

== Description ==

CT Core is a modern WordPress plugin designed to provide essential block functionality for block-based themes. It includes custom Gutenberg blocks, block patterns support, and deep integration with block-ready architectures.

**Key Features:**

* Custom Gutenberg blocks
* Block patterns support
* Extensible block architecture
* Smart Custom Fields (SCF) integration
* Performance optimized and lightweight

== Installation ==

1. Upload the `ct-core` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Start using the custom blocks in the WordPress editor

== Frequently Asked Questions ==

= Does this plugin work with any theme? =
While it works with most themes, it is specifically optimized for WordPress block themes (FSE).

= Are there more blocks available? =
Yes, CT Core Pro offers additional premium blocks and advanced customization options.
